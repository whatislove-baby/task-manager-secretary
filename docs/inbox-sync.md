# 一键收取新邮件

在主侧栏进入“收件箱”，点击“收取新邮件”。已连接邮箱会一次收取最近7天的收件箱邮件，保存正文和附件索引；已完整保存的同一封邮件自动跳过。邮件多时后台分批继续，无需逐封选择。

收取不使用以前保存的主题、发件人或仅未读筛选，也不改变这些高级预设。收件箱搜索框只过滤本地显示，不限制本次收取范围。账户连接和更早历史范围仍在“邮箱设置”中管理。

界面显示收取进度及新增、跳过、失败、正文未完整等结果。关闭收件箱页面不取消后台工作，返回后可看到进度；暂停或异常后可以继续。没有连接邮箱时，入口提示先去设置。

收取本身不调用模型，不发送或删除邮件，不自动保存正式待办。已启用的定时整理使用自己的既有计划。对话中的“选择邮件”用于指定参考资料；它的“刷新列表”只重读本地列表，与主收件箱的远端收取不同。

## 测试批次

对 `[TM演练 1121]` 的12封样本，点击收取完成后搜索 `TM演练 1121`，应看到E01–E12；E02有PDF，E03有Markdown。再次收取不应新增同一批副本。若此前定时流程已经导入它们，第一次手动收取也可能显示新增0，这时以本地是否能找到12封为准。

这只验证收取。后续再通过自然对话测试跨邮件理解、实际附件读取、澄清、文件生成与草稿审核。
