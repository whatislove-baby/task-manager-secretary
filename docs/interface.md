# 周视图与待办详情

本页记录2026-10-29用户给出的前端布局及高性能模型复核后的实现规格。

## 用户规则

- 顶部周一至周日，默认选中今天，可选日期、前后周和回今天；周格预览标题。
- 左侧只展示所选日截止的顶层待办，以及每天都出现的无截止顶层待办；包含完成项。默认按创建顺序，拖拽仅改显示排序且持久保存。
- 无截止不进周格。不增加无截止、逾期单独入口；过期事项回选其日期查看。
- 子待办只在右侧父树展示；子项显式设置了与父项有效截止不同的日期，才在周格展示并标注父名。父无截止、子有独立日期时也显示该子项。继承及同日子项不进周格。
- 点击周格子项可在右侧定位完整父树和该子项，即使父项不在当天左列，也不往左列插入子项或无关父项。
- 左侧可创建顶层待办；右侧可在任意层级添加子待办。选中事项先显示只读标题、备注和截止，点击“编辑任务”才进入原字段预填的编辑态；取消或保存成功后回到只读态，保存失败留输入。
- 新建根项和子项默认“仅日期＋今天”（本机当天，与当前选中日期无关），用户可修改。取消创建子项返回对应父项只读详情，保持任务树上下文。
- 周格预览包含独立完成小圆点，支持完成/取消完成；点击小圆点不改变选中日期或任务，沿用后端完成联动。
- 右侧保留树上的完成小圆点与“＋子任务”；移除可见的“完整任务树”标签，以及详情下方重复的“标记完成”“添加子任务”按钮。
- 任何操作都不在页面顶部显示通知横幅，成功操作静默；错误与必要业务提醒显示在对应窗格或当前工具窗口内。完成状态直接反映在圆点和标题横线上，详情不重复显示完成状态文字。
- 乌鸦悬浮窗进入首个可用版本，规则见下节。

## 设计与工程默认值

- 1280×850：外间距24，区块间距16，顶部44导航+约144周格，下左340/下右自适应；窄窗口保留可访问内容，长标题换行。
- 雾灰#D3D6D2、浅雾面板#ECEDE8、灰蓝#AAB7C3、深蓝#40586C、炭黑#25282A、桃粉#F3C6BC、暗紫#706074。今天与选中日期用不同标记；不制作蓝白模板。
- 整条左侧任务可拖动，拖过其他任务时实时预览新位置，松手后保存；取消拖动或保存失败恢复原顺序。按所选日期分别保存，新项目按创建顺序追加，保留上/下移按钮。
- 七个周格读取各自日期的已保存排列，当前日期使用拖动中的实时顺序；周格内顶层项与左列同序（无截止项仍不进入周格），独立子项随所属根的排序，未参与排序的项保持创建顺序。
- 周格最多显示三项，剩余可展开或滚动；没有截止的子项不会由于继承而重复预览。
- 未保存修改切换日期/任务/工具时，提供保存并切换、放弃并切换、继续编辑。保存失败保留原位置与输入。
- 右上工具区承载AI草稿、回收站、配置；主界面保持周视图、左列表、右详情。
- 日历使用本机日历日，日期型截止不补时间。分钟型转换为本机日期归入周格。

## 窗格与导航交互

- 应用高度固定在视口内；整体页面不滚动。下方工作区允许收缩，左右栏独立滚动，新增表单位于左侧滚动区域内，不撑开页面。
- 左右栏标题固定；右侧长任务树可在树区域内滚动，详情内容在右栏内部滚动。新建时仅重置左栏滚动位置，定位树节点只操作对应窗格。
- 前后切周进入非当前周时选周一；返回当前周时选今天。未保存修改仍经过原有切换保护。
- 周格空白、空态文字与非任务区域都可选中该日；日期按钮保留键盘操作。任务预览和完成小圆点分别处理点击，阻止事件冒泡，避免选中的任务被外层清除；两者为相邻按钮，避免嵌套交互控件。

## 验证

自动化覆盖投影、跨周日期、重启排序、数据库升级、原组件编辑与日期切换等实际执行范围。桌面真实点击/视觉结果单独记录，未执行不写通过。


## 乌鸦悬浮窗 · 首版

采用原生透明、无边框、置顶窗口。收起为约380×154，展开为约380×560并约束屏幕工作区。默认仅显示乌鸦、树枝与羽毛挂饰，无顶部文字工具条或底色。拖动乌鸦、树枝、羽毛、盘旋鸟和标题纸签均可移动悬浮窗；移动超过5px才进入拖动，轻点保持原点击功能，纸笺表单控件不参与拖窗。枝头区域不横向滚动。鼠标移入或键盘聚焦时显示关闭图标；主界面提供开关与退出。

- 数据范围与当天主列表一致：当天截止及无截止顶层项，不重复计入子项。枝上最多显示5只乌鸦；未完成事项超过5项时，枝外仅增加一只盘旋小乌鸦，表示还有更多待办，可点击打开完整名单；列表仍展示全部事项。零项显示空枝。
- 使用透明PNG彩铅乌鸦与细枝替代旧粗描边SVG，配色以靛灰蓝、石墨、少量鼠尾草绿为主；羽毛挂饰与暖白纸笺细化边线，出处与生成提示词见art-design.md及art-sources.md。
- 悬停或键盘聚焦时鸟歪头/抬翅并显示标题；羽毛挂饰打开今日名单，点击鸟则只打开单项详情，两者互斥。名单和详情用绑枝纸笺样式呈现，正文区域规整可滚动；显式编辑预填标题、备注、截止，支持日期/分钟和取消。
- 今日列表未完成在前、完成在后，组内保留当日用户顺序。保存完成成功后对应鸟振翅飞走再消失，保存失败保持原状；重开后鸟归枝，联动完成也按快照变化处理，减少动态效果模式停用动画。
- 两窗共用后端服务、数据库和完成联动；写入成功广播同步，跨午夜重新计算今日范围。跨窗更新不覆盖编辑草稿，保存校验原revision。
- 关闭主界面默认隐藏到托盘；可从悬浮窗或托盘重开主界面。偏好中可改为关闭时退出全应用，明确退出操作仍保留未保存修改保护。数据服务仅在应用真正退出时释放。
- 没有页面顶部通知横幅；错误与必要提醒留在当前窗格中。

飞走与盘旋采用8帧彩铅展翅图集，翅膀抬起/展开/下拍/回收逐帧变化，内层拍翅与外层轨迹独立；静止在枝头时保持原站姿。


固定站位绑定待办ID，完成时保留槽位直到飞离结束，其余鸟不重排；新待办或候补鸟进入空槽时播放远处飞来落枝动画。首读直接站好，刷新或列表排序不会使已有鸟换位。每个站位下有常驻小纸签标题，最多两行，长标题省略并保留悬停全文；纸签不随鸟飞行动画移动。

拖动只调用原生位置接口，保持当前收起/展开尺寸；释放、失焦或捕获丢失后抑制拖动衍生点击，实际键盘激活仍可打开面板。移动错误在现有窗口范围内显示，不触发展开。


Windows原生窗口显式关闭thickFrame、圆角和阴影；收起/展开分别设置固定最小最大尺寸，移动按当前模式固定宽高提交，避免系统边框尺寸误差被反复累加。拖动后的点击抑制继续保留。

系统托盘提供打开主界面、开关悬浮窗、退出应用；主界面原生最小化事件及“最小化到托盘”按钮均隐藏主窗，保留数据服务。退出仍经过未保存内容保护，最终退出时销毁托盘。


## Canvas 一键同步

主界面新增“同步 Canvas”。首次保存Calendar Feed链接后直接同步；有配置时点击入口会自动同步一次，不再预览勾选。使用专用窗口承载进度、错误、计数和新增/更新清单，禁止顶部横幅。更新可展开查看原/新标题及截止时间。

同步期间禁重复操作，StrictMode不重复触发；失败保留尚未保存的链接，支持重试、更换和移除订阅。关闭含未保存链接的窗口需确认，焦点留在窗口内。主界面和悬浮窗通过已有变更广播刷新，编辑中的草稿不被自动覆盖。


Canvas来源区域与个人备注独立，默认不铺开长文。点击阅读入口显示完整纯文本阅读层，固定窗口内独立滚动，支持关闭/Escape、键盘焦点管理及返回原入口。主界面和乌鸦任务详情共用来源组件；原文通过后台使用已保存事项链接在系统浏览器打开。同步结果可显示说明/链接发生变化，以及逐项跳过原因。


Canvas 同步仅提交截止日期为本机今天及之后的事项；分钟按本机时区换算日历日，不以当前时分排除当天事项。在入库前重新确定今天，避免网络请求跨午夜后导入昨日事项。已保存历史项不自动删除；同步结果expired计数并包含于skipped，不列为异常。此规则不修改底层通用ICS解析范围。


## 邮箱工作台

邮箱模态提供账号列表、本地邮件列表、正文预览，各列独立滚动。账号列表可同时勾选多个邮箱，添加入口按IMAP／Microsoft365绑定方式分类；各账号设置为独立视图，连接和读取范围分两列，文件夹区域至少200px高且不被flex压缩。关闭未保存设置有局部确认，离开设置清除口令输入。

默认按各账号保存的条件导入最近7天未保存邮件，正文进入本地库。支持本地搜索、分析状态筛选、分页、当前页全选与跨页选择。分析状态与服务器未读互不关联；只显示未分析／已分析，不以待办保存状态作为邮件状态。下方填写用户要求，展示发送内容、服务与模型，选择部分或全部筛选结果分析。长文分段、数量上限明确提示。

点击主题离线预览正文；查看已保存分析不重发AI。批量分析转Tools审核，展示用户要求、邮件数量、模型、说明与草稿；只总结无草稿也保存分析。审核后选择保存，重开已保存批次只读。成功静默，错误与导入报告留在邮箱模态，不出现全局顶部横幅。

## 启动与关闭

偏好新增即时保存的“启动与关闭”：开机自动启动、启动时默认打开悬浮窗、关闭主窗到托盘／退出全部。默认前两项关闭、关闭主窗到托盘。托盘右键退出与关闭悬浮窗×分别保持全退出／仅关闭悬浮窗含义。


## 后台邮件与会话工作区（2026-10-31）

邮箱及AI整理入口共享后台任务栏。任务启动立刻返回，可暂停／继续，可收起邮箱界面继续操作待办。底角显示状态与返回入口，不使用顶部全局提示；导入完成返回邮件，分析／对话完成返回历史。关闭未发送对话内容或未保存设置仍有保护，已经提交的后台任务不阻碍收起。

设置中提供账号独立命名预设、包含／排除文字、多发件人按行填写及已知发件人勾选。选择预设填入条件，应用为账号读取条件用于导入；侧栏动态显示实际日期范围。

本地归档支持全部／未归类／自建文件夹视图、创建改名、批量移动、删除正文前确认。确认明确保留导入记忆，不影响服务器；移除文件夹只解除归类。AI历史独立滚动，展示每轮输入／答复及草稿审核入口，能新建文字对话、追问及删除会话记录；未发送文字不因切换会话丢失。显示状态仅未分析／已分析，服务器未读仍是独立筛选条件。

悬浮窗透明区域按真实图案透传下层点击，图案拖动、纸签和展开表单保持正常；不按图片矩形判定整个区域可点击。


## 邮件信息层级与悬浮交互修订（2026-10-31）

分析进度分别展示邮件数量和批次数，例如“15封邮件 · 分析批次0/4”，不把批次当邮件数。设置页独立显示当前生效的预设名与条件摘要；条件规范化匹配命名预设，多个同条件名称会注明匹配，未应用编辑另行提示。“应用这些读取条件”完成切换。

左栏仅保留账号／连接／读取设置与文件夹导航管理，中央提供导入、归档移动删除及AI操作，折叠操作栏避免列表被挤压。未分析／已分析用整行双色底、明显不同的标签与文字共同区分。

关闭图标保留900ms跨空白可达时间，透明区域仍穿透；关闭图标自身不触发无限显示。枝头按稳定槽位给微小旋转、比例及呼吸节奏差异，爪子锚点与其他鸟的站位不变；减少动态效果时停用呼吸动画。
