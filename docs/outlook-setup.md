# 学校 Outlook 首次连接

正式Python后端使用OAuth授权码流程及PKCE登录，通过Microsoft Graph读取邮箱；旧TypeScript后端中的MSAL不是当前实现。用户在系统浏览器完成学校登录及多因素验证，应用不收邮箱密码或客户端密钥。Windows凭据由DPAPI保护；Mac凭据使用Fernet加密，主密钥保存在登录钥匙串中。

## 一次性注册应用

当前源码不含公共注册的微软应用标识，需先注册属于自己的应用。应用程序（客户端）ID 是公开标识，不是密钥。

1. 在浏览器打开[Microsoft Entra管理中心](https://entra.microsoft.com)，使用有应用注册权限的账号登录。
2. 进入“标识 → 应用程序 → 应用注册”，选择“新注册”，名称可填 Task Manager。
3. 支持的账户类型选择“任何组织目录中的账户（多租户）”，用于学校或工作 Microsoft 365 邮箱。
4. 注册后进入“身份验证 → 添加平台 → 移动和桌面应用程序”，添加重定向 URI `http://localhost`。这是本机接收登录结果的临时回调，不是部署公网服务器。
5. 在“API权限 → 添加权限 → Microsoft Graph → 委托的权限”添加`User.Read`和`Mail.Read`，分别用于识别登录账号及读取邮件。程序还请求`openid profile offline_access`用于登录及续期；不需要发送、修改邮件权限或客户端密码。
6. 返回“概述”，复制“应用程序（客户端）ID”。在Task Manager打开“邮箱”，选择“Microsoft 365（浏览器授权）”，点击“添加邮箱”，填写客户端ID并点击“保存连接设置”。
7. 点击“连接此邮箱”，在系统浏览器选择学校账号、完成登录和授权；成功后返回应用设置读取范围。

菜单名称可能随管理中心语言稍有差别。没有注册权限时，请由允许注册的开发者账号注册多租户应用，或联系学校管理员。学校若要求管理员批准第三方应用，应由管理员审核后授权；不能通过更换前端或粘贴密码绕过学校策略。

## 使用

在该邮箱“设置”中选择文件夹和读取条件，点击“应用这些读取条件”；未选择文件夹时默认收件箱。筛选支持最近N天、指定收件日期起、起止日期、发件人、主题及仅未读。返回工作台，勾选该邮箱，在“导入邮件”中点击“导入所选邮箱”，把匹配的正文保存到本地。

最近N天包含今天；日期按本机时区计算，结束日包含整天。每个账号最多导入200封匹配邮件，达到限制请缩小范围。读取不改变服务器已读状态；正文以纯文本显示，不加载远程图片或执行HTML。附件只显示信息，不下载或交给AI分析。

勾选本地邮件并点击“分析已选N封”才发送正文至已配置的AI服务。当前按邮件逐封分析，长正文分段处理；全部成功且正文完整后才标记“已分析”。待办仍需在“AI对话历史 → 审核本轮待办草稿”中核对并确认。可以重新分析；新分析再次确认可能重复创建任务，并不会自动更新已有Canvas任务。

原会话追问会重新带入选中邮件的本地原文、最初要求和历史；来源上下文超过24000个UTF-16字符时会提示缩小选择，不会静默省略正文。AI设置、自定义OpenRouter地址、分析限制和备份方法见[通用绑定指引](mail-setup.md)。

“断开此邮箱”清除该绑定的登录凭据，不删除本地邮件或待办。迁移data到其他设备或系统账号后，需要重新授权；Mac还依赖当前登录钥匙串，单独复制data不足以恢复凭据。请先完整备份再处理配置，不要删除tasks.sqlite。允许IMAP授权码／密码的邮箱也可使用另一绑定方式。

## 常见问题

- 提示应用标识无效：核对客户端 ID 是否完整，应用是否按组织账户注册。
- 提示重定向不匹配：核对桌面平台配置中的 `http://localhost`。
- 提示需管理员批准或读取被拒绝：联系学校管理员审核该应用及委托的`User.Read`、`Mail.Read`权限；本地程序不能自行解除。
- 登录失效：重新连接学校 Outlook，不需要删除待办数据。
- 未看到某个文件夹：展开父文件夹；当前只列普通非隐藏文件夹，不读取共享邮箱或本地 PST。
