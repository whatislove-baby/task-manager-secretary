# Task Manager · 产品使用说明书与流程图

这份资料面向第一次使用产品的同学。**完整说明书是 `user-manual.pdf`，两页 `product-introduction.pdf` 仅作产品概览。**

| [完整图文说明书 HTML](user-manual.html) | 可点击放大截图、显示或隐藏标注；下载后离线打开。 |

**整包下载：[产品说明书与流程图 ZIP](https://github.com/whatislove-baby/task-manager-secretary/raw/refs/heads/main/docs/task-manager-product-kit.zip)。** 解压后打开 HTML，相关资源已包含在包内。GitHub 页面会显示 HTML 源码，请先下载再用浏览器打开；PDF 与图片可在 GitHub 直接预览或下载。

图例：灰色表示沿用的上游业务或开源机制，蓝色表示本应用新增／改进，橙色表示用户操作；虚线框分开用户、AI 和后台。图内包括 Deep Agents、LangChain 与 LangGraph。

说明书沿用已公开的真实应用截图，使用合成课程与实习资料，不含真实邮箱账号和密钥。公开示例的测试范围与未通过项目仍以仓库中的逐轮记录为准。
