# 公开演示与图文手册

入口为 `index.html`；`user-guide.html` 展示24张真实应用截图；请连同相对图片资源一起离线阅读。SVG 框和箭头是可隐藏的单独图层，点击截图可查看原图，未替换页面文案或修改截图像素。

## 示例资料

- 秘书：全合成邮件从空收件箱经过产品真实 IMAP 读取流程导入；外部服务器由本地协议夹具替代，分类和任务使用真实 API。展示收件分类、保留原文、独立任务对话与返回秘书，不能等同于真实外部邮箱服务器验收。

- 学生：虚构课程、老师和社团的自然措辞邮件。使用真实 API 产生的待办/改期草稿，以及人工审核前白名单快照；截图回放在独立副本中真正保存一条待办并检查本地日历。
- 实习：完全合成的校园职业中心部门、同事、邮件、报名表和说明。新建独立资料库与会话，使用真实 API 生成 Word、PDF、检查结果和回复草稿；截图取自这次独立运行的实际结果。
- 学生和实习两条线的邮件均预先通过产品解析器导入本地。这两条线没有实测 IMAP 收信，没有发送邮件或写外部日历。
- 截图库没有 API 密钥或邮箱账号；“尚未配置模型”是专用截图资料库的真实状态。新问答/真实收发需用户自己配置。

## 复现与交接

本仓库不包含本机数据库快照或离线演示启动器。按根目录 README 构建后，使用合成输入在自己的隔离资料库中练习“待确认 → 核对 → 保存 → 本地日历”。这不等于团队成员已完成课程要求的交接，仍需同学亲自操作并记录。

- `clone-guide-profile.py`：只复制白名单业务 SQLite 和登记文件，不含设置、账号、vault、Keychain或缓存。
- `capture-guide.cjs` 与秘书截图脚本：启动交付的 Mac 应用，在隔离副本中导航并拍真实截图。
- `build-guide.py`：构建24图手册与哈希清单，拒绝混用不同 ASAR 的截图。
- `verify-guide.cjs`：离线检查内嵌图、导航、放大和标注开关。
- 公开安全核验扫描文本、SQLite、登记文档、链接和本地 OCR 文字；结果见 `public-safety-scan.json`。原始证据不以改名方式伪装成新案例。

实际测试范围与限制见 `TEST-REPORT.md`，文件来源及截图哈希见 `guide-manifest.json`。任何结构检查通过都不等于内容和排版必然正确。
