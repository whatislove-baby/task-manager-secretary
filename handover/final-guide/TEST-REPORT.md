# Task Manager：公开演示测试记录

执行日期：2026 年 11 月 22 日。公开演示只使用虚构课程、社团和校园职业中心资料。课程、实习和秘书场景的输入与真实模型结果分开保存；不把模型说“完成”当作测试通过，也不把内部历史案例改名后充当本次新测试。

## 环境与边界

- 使用现有 OpenRouter DeepSeek、官方 Deep Agents / LangGraph、真实文件处理与持久化接口。
- 课程与实习的合成邮件由产品 MIME 解析器预先导入本地；新增秘书场景从空收件箱经过实际 IMAP 读取流程导入，但远端服务器用本地协议夹具替代。两者均不冒充真实外部邮箱服务器验收。
- 所有任务和文件写入独立演示资料库。截图副本没有 API 密钥、邮箱账号或个人缓存。
- 发送被阻止，无 SMTP 发送回执；日历是应用内 Todo 视图，不是外部日历写入。
- 手册使用真实应用截图与独立标注层，没有替换页面内容或重画界面。

## 实习：活动报名资料到简报与回复草稿

此处使用全新独立会话与合成资料：校园职业中心的虚构同事、活动报名 CSV 和简短说明。验收要求为读取原始资料 → 统计并生成含表格的简报 → Word 转 PDF → 检查实际页面 → 将两份当前文件加入正确回复草稿。

本次 **94.91 秒自然完成**，没有重试或人工修补产物。产出 1 页 Word 和 1 页 PDF、可核对的统计表，以及一份仍未发送的回复草稿。独立读取原件、页面与持久化草稿后，37 项检查全部通过：

- 三场活动的已报名数为 42、34、30，剩余名额为 18、6、20；合计 106 报名人次，明确不等于去重人数。
- 原输入字节未变，Word→PDF 有真实来源记录；另起 LibreOffice 转换后与交付 PDF 逐像素一致。
- 回复对象为合成同事周宁，草稿对应本次邮件，并实际包含当前 Word 与 PDF 两个附件；SMTP 发送数为 0。
- 两份页面已独立目视核对，没有发现缺字或裁切。本次只有 1 页，不能据此推断任意长报告都会成功。

证据：[全合成输入与运行报告](../public-demo-intern/README.md)、[独立核验](../public-demo-intern/independent-audit/verification.json)、[人工页面检查](../public-demo-intern/independent-audit/review.md)、[可重载快照](intern-test/README.md)。内部历史文件测试不替代本案例。

## 仍需人工判断

结构通过、页面可以渲染、模型认为排版通过，分别是不同层面的证据，都不保证事实与数字必然正确。正式保存或发送前应核对日期、来源、图表、收件人和当前附件。复杂模板或字体缺失可能造成转换差异；任意扫描 PDF 原位改字、通用联网代理、任意第三方技能包直接运行均不在本次公开验收范围。

报告生成仍可能耗时数分钟，模型连接可能失败；应按执行状态恢复，不能把中间文件当成最终交付。本地定时整理也依赖电脑运行。
